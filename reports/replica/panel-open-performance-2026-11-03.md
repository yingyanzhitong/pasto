# Pasto 面板拉起性能排查

2026-11-03 · Pasto 1.0.2 / Paste 6.6.6 · macOS 26.2 · Apple Silicon · SDK 26.5 Release

**已复现 Pasto 的拉起延迟。此报告包含 Pasto 的隔离实测与 Paste 的反编译基线，没有取得原版同条件的端到端计时，不能计算“比 Paste 慢几倍”。**

## 实测结果

使用当前源码的真实 UI、Core Data 和卡片代码；复制本机数据库到 Git 忽略目录，原数据及设置不改动。数据共 441 条，历史集合 420 条、2 个分组。测试面板放在屏幕外，不注册全局快捷键、不采集剪贴板、不启用云同步。3 次独立进程，每次首次展开 1 次、重复展开 8 次，共 27 次。以下是排除采样器与窗口轮询后的正式批次；另存诊断批次不混入统计。

| 指标 | 首次展开（3 次） | 重复展开（24 次） |
| --- | ---: | ---: |
| `showPanel()` 同步返回，中位数 | 343.0 ms | 24.6 ms |
| 展开完成回调，中位数 | 572.6 ms | 356.9 ms |
| 展开完成回调，范围 | 526.8–812.0 ms | 348.3–362.0 ms |
| 每轮最大主 Actor 探针间隔，中位数 | 131.9 ms | 8.1 ms |

计时从 `showPanel()` 调用开始；首次包含惰性窗口创建，重复展开复用窗口。数据库加载已单独完成，不混入表格。完成回调表示程序的展开动画组完成，**不等于屏幕首帧、光标可用时刻或按键到像素延迟**。主 Actor 探针每 2 ms 尝试恢复，间隔包含调度延迟，不能直接换算成 FPS。屏幕外测试也不能代替真实屏幕的 GPU/液态玻璃流畅度测试。

## 与原版的对照

| 项目 | Paste 反编译证据 | 当前 Pasto |
| --- | --- | --- |
| 内容展开动画 | `0x1000192b0` 调用 `0x10021cadc`，时长常量解码为 150 ms | 同样设为 150 ms |
| 窗口初始化 | `0x1000187d0` 创建 MainWindow/MainView，并执行布局 | 惰性创建窗口，使用外层及卡片 `NSHostingView` |
| 真实端到端展开耗时 | 本轮未可靠测得 | 本轮仅测得上表的程序调用与完成回调 |

两者动画配置相同，因此不能通过把动画改短来解释或解决全部差异。原版创建窗口的函数还使用 `styleMask=0x88`、`defer=true`；Pasto 的创建参数不同。这是后续需要对照的窗口行为差异，不能直接据此断定耗时根因。

## 已定位的开销

1. **首次构建成本高。** `loadPanel()` 在第一次 `showPanel()` 内创建 SwiftUI 承载视图并执行布局。首次同步返回明显慢于窗口复用；在这段同步调用结束前，面板已经无法即时响应同一主线程的新操作。
2. **卡片更新存在数据转换和解码开销。** 真实探针进程的采样记录包含 `ReplicaPanel.layoutIfNeeded → NSHostingView.layout`，以及 `ClipboardPersistence.item`、预览元数据 codec、JSON/PropertyList 解码。源码中 `tileCells()` 对可见卡片读取 `resolvedItem()`；`updateRoot()` 的渲染签名只能在此读取之后避免重建，不能阻止此前的数据转换。卡片正文、页脚及上下文菜单还会访问派生元数据。需要按数据修订标识避免重复解析，不能仅按 UUID 永久缓存导致编辑后显示旧值。
3. **默认窗口动画有可测影响，但不是唯一问题。** 仅在隔离探针中，把窗口初始化后的 `animationBehavior` 改为 `.none`，日志确认值为 2。再做 3 个独立进程、24 次重复展开，完成回调中位数从 356.9 ms 降至 231.8 ms，下降 35.0%。首次展开仍有明显延迟。这是诊断实验，**尚未写入应用，也未证明 Paste 原版使用相同设置**，不能作为已完成的一比一优化。

## 建议优先级

- P0：细分并减少首次窗口构建、布局及首批卡片准备的主线程工作；对照原版控制器创建时机。
- P0：记录可见卡片的投影、预览解码调用次数，复用未变化内容，保留编辑失效与实体观察语义。
- P1：对照原版窗口创建、显示与动画设置，验证系统窗口效果与内容滑入的组合，不直接照搬实验开关。
- 验收：保留同一数据副本和指标，再补齐两款应用在相同屏幕、数据规模、触发方式下的真实画面测试；当前不提供快慢倍数或帧率结论。

## 证据与边界

自动化按键到窗口出现的尝试被排除：测量进程没有键盘监听权限，自动化输入也未可靠更新其观察到的按键计数；WindowServer 轮询自身出现较长等待。未将工具派发耗时或其 AX 等待当成应用延迟。

本次只新增报告及忽略目录内的测试工具，未修改生产源码、重新安装、提交或发布。原版临时启动后已退出，Pasto 原有进程保留。完整时序统计及源码哈希见同名 JSON；忽略目录中的探针源码、原始 JSON、采样栈及原版函数片段位于 `.local/panel-open-performance-20261103/`。其中真实数据副本仅保存在本机，不应提交。
