# P0/P1 多选与 Stack 批量复核

本轮对照实际多选输入、Stack 采集、重复项、反转、快捷粘贴和会话关闭，**未发现新的已确认差异，复用现有实现，未修改应用源码**。

| 链路 | 有限源码核对结果 |
| --- | --- |
| 多选输入 | 从实际 applied collection 和有序选择数组读取原生输入，复制、粘贴和加入 Stack 不从 Set 推导顺序，也不重新拼接较新的值快照。 |
| 采集与重复项 | 从新建历史 collection 的第一项取得原生实体；每次插入一个出现位置，不去重。最后一个同 ID 出现位置移除后，才释放该 ID 的原生输入映射。 |
| 反转与方向 | 先反转队列，再切换并保存后续插入方向；数组中的重复项保留。 |
| 全局快捷粘贴 | 保留原生输入，先弹出一个队首、更新快捷键状态，再调用恢复/粘贴。失败不补回已弹出队首；空队列关闭会话。现有实现与这个容易误改的原版顺序一致。 |
| 注册与关闭 | 队列可用性控制快捷键注册，注册不先检查辅助功能权限；恢复服务处理权限。关闭释放内容和观察者并清空临时队列，重新打开不恢复旧版保存的 UUID 队列。 |

另外核对了按数字 row 移除一次出现位置的原版数组操作，以及 Pasto 现有的 expected-ID/revision 保护。保护属于 SwiftUI 适配边界，不据此声称原版非法 index、所有回调过期和重入输入完全相同。

## 不混同原版和扩展

“把当前多选加入 Stack”和每行菜单“粘贴”是 Pasto 已有扩展，不能仅凭存在便算作迁移了原版同名原生菜单。

逐行菜单粘贴在请求成功后移除所选 row；**原版全局 Stack 快捷粘贴则在恢复前弹出队首**。本轮分别核对并保留两条路径，没有为了统一形式而改变原版快捷粘贴顺序。

原版收费授权及联网分支按用户范围排除；本轮没有迁移付费检查或任何绕过代码。Stack 窗口布局、完整动画和其他 P2 样式不进入本轮。
