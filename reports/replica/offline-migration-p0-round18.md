## 确认差异

原 IndexingState 有 schemaVersion、totalItems、indexedItems、oldestTimestamp（Date?）和 invalidItems 五字段。启动先检查索引可用性，再读取状态和来源身份；身份改变、状态不存在或 schema 不同进入重建。同 schema 未完成时使用最旧时间恢复，已完成且数量大于零时才探测索引健康。

健康探测使用历史时间大于等于 1970 年的查询：成功却无结果才确认空索引；查询错误记录诊断并返回 false，不能等同确认空结果。原 schema 在 macOS 26.4 前为 5、达到后为 6，与 Pasto 归档 version=1 的用途不同。

Pasto 当前只有内存 indexed 快照和冷启动 needsReset；本地 Core Data 保存自有实体，revision 每次保存改变，不能冒作稳定数据源身份。以上 13 个原地址记为已确认缺失合同，未用相似代码增加 partial 或完整迁移计数。回到 P0 数据与持久层，先核对原 CDSearchIndexerDataSource、ItemRepository 和本地变更接口，再接完整状态恢复。
