## 修复

原 `0x1001ebce4`、`0x1001ec200` 在冲突发生处创建携带 String 的错误，并直接传递递归得到的错误；Pasto 此前返回 `String?`，外层 `OriginalShortcutValidatorService` 再构造错误。

本轮将两个方法及其重载改为返回既有 `OriginalShortcutRecorderError?`，只在系统/菜单冲突分支构造；服务直接转交为 `Error?`，不重复包装。已检索所有源码、Swift 测试及脚本调用处，没有遗留以返回值作为 String 使用的调用。上一轮的菜单惰性读取和两次键名解析继续保留。

这里对齐错误的生产与传递位置，不声称独立应用的 Swift 运行时类型身份、全部本地化选择与原框架等价。
