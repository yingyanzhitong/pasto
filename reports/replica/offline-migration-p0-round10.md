## 确认并修复的差异

原生产调用链为 `0x1002d6274 → 0x1002e19c8 → 0x1002e2930 → 0x1002e2bf8`：factory 明确传入 **100**，构造函数将其放到 `self+0x20`；异步结果每取一个 uniqueIdentifier 放入数组，计数达到该值便停止。迭代完成或达到上限后还会执行 `Task.checkCancellation`，再把结果交回父层。

Pasto 原来一直遍历全部结果，完成路径缺少显式任务取消检查。现增加真实生产常量 100，每个原始返回结果先计数，再做命名空间和 UUID 投影；到第 100 条停止，并在发布结果前检查取消。计数使用原始返回条数，不能以去重后的集合大小或有效 UUID 数替代原数组 count。已有 pending/request 检查继续阻止旧结果发布。

不是只根据伪代码或名称猜配置。本轮局部反汇编、立即数及真实导入绑定确认：

| 静态位置 | 确认内容 |
| --- | --- |
| `0x1002d62b8` | `mov w2,#100`，下一条调用 `0x1002e19c8` |
| `0x1002e2cd0` | 读 `self+0x20`，与结果 count 比较，不等继续 |
| `0x1002e2cf0 → 0x100bf84c0` | 调用经声明 dyld 指针链绑定到 Swift Concurrency 的 `Task.checkCancellation` |

保存了原字节、原切片 SHA-256、SDK stub 和实际 dyld import，而非从 objdump 邻近符号标题推断目标。以上均为静态解析，没有执行原函数。

## 已有实现直接复用

本轮直接核对 22 个地址，复用以下真实实现：

- query filter 按原 tag 和 raw String 去重保序，trim 仅用于判空；原输入最后 filter 为文本分界，最终为 filters + 后部 text + 前部 text，不重排或合并 raw 文本。
- FFFC 替换、Character 空白连续分段、有效 query 判空；自由文本单空格连接后依次转义反斜杠、引号、星号、问号。
- 同 tag 筛选 OR、不同 tag 与自由文本组 AND，保留原 cd/cwdt 条件、26.4 的 description 门控和 ISO 日期解析边界。
- 搜索输入 snapshot 包含 nodes 与 NSRange；0.4 秒合并、immediate 先 flush、Undo 先 flush、Redo 不 flush、reset 不改 current 等不对称规则保留，真实编辑器消费者已接。
- 索引文本按 Character 前 5000 个截取、distantFuture 及属性门控等子行为直接复用。

另外 **31 个搜索相关旧合同**满足严格复用条件：合同与已有人工审阅一致、原切片/逐函数伪代码摘要一致、全部关联源码摘要一致且真实符号引用存在。覆盖部分搜索外观/图标、过滤 popover、日期预设和日期编码。它们是证据未变后的复用，不宣称本轮重新人工逐行核对，也不重复增加迁移计数；记录逐条保存旧证据路径和摘要。
