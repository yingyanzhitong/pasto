## 本轮结论

- 普通本地删除许可的真实谓词可复用，共享权限分支排除。原空选删除仍进入事务/回调，当前会直接返回；保留现有保护，只记录差异。
- 原 history 删除路径会 first-fetch 后 `refreshObject:mergeChanges:true`，当前增量持久化没有同一副作用；原数组逐项删除与当前 Set 差集遍历的顺序、重复处理也不同。
- 原 coordinator 在 onDidShow 后交付可见状态和快照动作，当前在预显示钩子接焦点快照；toggle、有限弱关闭回调及若干事件/动画叶子可复用。
- 原 unknown/无路径文件使用归档 MD5；下层归档键已证为 `data`，当前 `dataByType`，实际采集还屏蔽未知摘要并改用表示值比较。这是可证策略差异，不虚报执行了 MD5 样例。
- 快捷键派发、录制和字符发送的有限合同可复用；注册 API 额外返回 OSStatus 且被实际 consumer 使用，与原 void 接口单列为适配差异。
- 修正“空但可见搜索框等于 search context”的误判；原上下文依据有效 query。history 恢复判据可复用，超时 onDismiss 的全部消费者效果仍未闭合。
- 图片/表示处理虽有有限算法相同，`31bcdc`、`37a144`、`38222c`、`383df4` 的完整实体输入、reload/缺失 UUID、来源和异常桥仍留待证，不以纯值函数替代原完整入口。
