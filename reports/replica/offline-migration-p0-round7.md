## 已修复的差异

原 `0x100378df4 → 0x10037ba14` 在读取 promised Data 前检查来源及过滤配置，不在许可检查阶段保存历史。Pasto 的 delegate 和 `allowsPasteboardCapture` 各额外调用一次 `save()`，即使内容随后被拒绝，也可能合并和提交本地状态。

两处改为现有只读 `reload()`：保留其他进程修改的偏好和尚未保存的本地编辑；读取及合并不提交数据库。暂停到期确实修改偏好的分支继续保存，生成内容的拒绝仍先于刷新。此处的跨进程刷新是 Pasto 独立存储适配，不声称原版有同一个 `reload` 方法。

## 已有实现直接复用

- **采集调度**：0.25 秒重复轮询、0.025 容差；changeCount 未变立即结束，变化时取消旧 timer，安排 0.3 秒的一次读取。原常量按 IEEE 双精度解码与当前源码比较。
- **读取与过滤**：先记录 count、清空暂存和触发 types getter，再检查访问许可；delegate 许可先于 Data 读取。按原 item/type 次序读取，累计大小最多 1 GiB；缺失和超限表示不计入累计，空 item 不入快照，回调后清空暂存。
- **类型判定**：从所有 item 的有序类型选择原 11 项优先级，原 raw kind 表与 Swift 枚举逐项一致。文本取 plainText/utf8PlainText/text/url；颜色及 URL 提升只看首 item；链接判定使用 trim 后完整 UTF16 区间。
- **成功事件**：保存 token、计数加一及同步通知先于空内容判断；创建成功后清 Undo，新建通知受 isNew 限制，成功捕获通知随后发出。完整仓库和 Stack 消费者时点不由这些外层分支自动证明。
- **表示存取**：重复类型仍按顺序保留；空 Data 与 nil 区分；多项通过原值 codec 存储，显式 snapshot 不额外读取系统字符串。unknown 归档 checksum 的类身份仍待核对，不能用独立类的归档摘要冒充原值。
